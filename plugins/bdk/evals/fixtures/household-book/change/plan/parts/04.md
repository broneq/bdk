# Part 04: Statement import

## Goal

`ledger import <file> [--account <name>]` adds the lines of a CSV bank statement as entries and skips duplicates, as spec `ledger-import` says (design D6).

## Uses

From part 01, exactly as named:

- The book holds `entries`, an entry being `{ date, description, amount, account, category: string | null }`, amounts in integer cents, dates `YYYY-MM-DD`.
- `src/cli.js`: `UsageError`; `parseArgs(args, names)`; `openBook(io)`, `writeBook(io, book)`; `requireAccount(book, name)`. A command module in `src/commands/<name>.js` exports `summary` and `run(args, io)`, with `io = { cwd, today, out, write, err }` (`out(line)` writes a line and a line break).
- `src/dates.js`: `isDate(text)` (a real calendar date `YYYY-MM-DD`).
- `src/money.js`: `parseAmount(text)` (throws an `Error` on anything that is not decimal units with up to two decimals), `formatCents(cents)`.
- `test/helpers.js`: `ledger(dir, ...args)` (returns `{ status, stdout, stderr }`), `newDir()`, `writeBook(dir, fields)`, `readBook(dir)`.

## Acceptance scenarios

- `ledger-import` / Requirement: Statement import / Scenario: Debit and credit columns
- `ledger-import` / Requirement: Statement import / Scenario: Quoted fields
- `ledger-import` / Requirement: Statement import / Scenario: Bad line imports nothing
- `ledger-import` / Requirement: Statement import / Scenario: Debit and credit both filled
- `ledger-import` / Requirement: Statement import / Scenario: Missing column
- `ledger-import` / Requirement: Statement import / Scenario: Import into an account
- `ledger-import` / Requirement: Duplicates / Scenario: Same statement twice
- `ledger-import` / Requirement: Duplicates / Scenario: Equal lines in one statement

## Tasks

1. Read CSV text into records with line numbers
   - File: src/csv.js, src/csv.test.js
   - Interface: parseCsv(text: string): { line: number, fields: string[] }[] (one record per non-empty line, lines split on \n or \r\n and counted from 1; a quoted field may hold commas, and "" inside it stands for one double quote)
   - Verified by: src/csv.test.js (plain, quoted with comma, doubled quote, \r\n, empty lines keep the numbering)
2. Map statement records to entry rows
   - File: src/statement.js, src/statement.test.js
   - Interface: readStatement(records, file): { date, description, amount }[] (records[0] is the header; columns by name ignoring case and surrounding spaces, the first of two equal names counting: date; description, else payee; amount, else debit and credit, debit negated; no record at all means no date column; dates YYYY-MM-DD or DD.MM.YYYY, checked with isDate after conversion; amounts with parseAmount; UsageError "<file> has no <date|description|amount> column", "<file> line <n>: not a date: <text>", "<file> line <n>: not an amount: <text>", "<file> line <n>: needs one of debit and credit" when both or neither are filled, at the first bad line)
   - Verified by: src/statement.test.js
3. Skip the rows the account already holds
   - File: src/dedupe.js, src/dedupe.test.js
   - Interface: freshRows(entries, rows): { fresh: rows[], skipped: number } where entries are the target account's entries; for every distinct (date, description, amount), with k equal rows and j equal entries, the first max(k - j, 0) rows are fresh, in row order
   - Verified by: src/dedupe.test.js
4. Add the command `import`
   - File: src/commands/import.js, test/import-cli.test.js, test/fixtures/statement.csv
   - Interface: summary "Import a bank statement in CSV"; `ledger import <file> [--account <name>]` (account defaults to "main", checked with requireAccount); reads resolve(io.cwd, file) with readFileSync (an absolute <file> is read as given), UsageError "cannot read <file>" on failure; appends every fresh row as { date, description, amount, account, category: null }; writes the book once, after every line converted; prints "Imported <n> entries, skipped <m> duplicates". test/fixtures/statement.csv holds the three lines of the scenario "Debit and credit columns"
   - Verified by: ledger-import / Requirement: Statement import / Scenario: Debit and credit columns, Scenario: Quoted fields, Scenario: Bad line imports nothing, Scenario: Debit and credit both filled, Scenario: Missing column, Scenario: Import into an account; Requirement: Duplicates / Scenario: Same statement twice, Scenario: Equal lines in one statement; test/import-cli.test.js
