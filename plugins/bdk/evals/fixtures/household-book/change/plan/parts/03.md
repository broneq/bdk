# Part 03: Categories and rules

## Goal

`ledger category add|list`, `ledger rule add|list` and `ledger categorize` work as spec `ledger-categories` says (design D5).

## Uses

From part 01, exactly as named:

- `src/book.js`: `isName(text)`; the book holds `categories: string[]`, `rules: { pattern, category }[]` and `entries`, an entry being `{ date, description, amount, account, category: string | null, transfer? }`; an entry with a `transfer` id is part of a transfer.
- `src/cli.js`: `UsageError`; `parseArgs(args, names)`; `subcommand(command, args, names)` (checks `args[0]`; then `parseArgs(args.slice(1), <that subcommand's options>)`); `openBook(io)`, `writeBook(io, book)`; `requireCategory(book, name)`. A command module in `src/commands/<name>.js` exports `summary` and `run(args, io)`, with `io = { cwd, today, out, write, err }` (`out(line)` writes a line and a line break).
- `test/helpers.js`: `ledger(dir, ...args)` (returns `{ status, stdout, stderr }`), `newDir()`, `writeBook(dir, fields)`, `readBook(dir)`.

## Acceptance scenarios

- `ledger-categories` / Requirement: Categories / Scenario: Add and list categories
- `ledger-categories` / Requirement: Categories / Scenario: Reserved name
- `ledger-categories` / Requirement: Categories / Scenario: Existing category
- `ledger-categories` / Requirement: Rules / Scenario: Add a rule
- `ledger-categories` / Requirement: Rules / Scenario: Rule for an unknown category
- `ledger-categories` / Requirement: Categorize / Scenario: Match ignores case
- `ledger-categories` / Requirement: Categorize / Scenario: First rule wins
- `ledger-categories` / Requirement: Categorize / Scenario: Category kept
- `ledger-categories` / Requirement: Categorize / Scenario: Transfers untouched

## Tasks

1. Add categories to a book
   - File: src/categories.js, src/categories.test.js
   - Interface: addCategory(book, name): void (UsageError "invalid name <name>" when !isName(name) or name is "none", which the entry filters reserve; "category <name> exists" when present); categoryNames(book): string[] in name order
   - Verified by: src/categories.test.js
2. Add rules and categorize entries by them
   - File: src/rules.js, src/rules.test.js
   - Interface: addRule(book, pattern, category): number (requireCategory first; appends { pattern, category }; returns the 1-based position); ruleMatches(rule, description): boolean (case-insensitive substring); categorize(book): number (sets the category of the first matching rule on every entry with category null and no transfer id; returns how many changed)
   - Verified by: src/rules.test.js
3. Add the commands `category` and `rule`
   - File: src/commands/category.js, src/commands/rule.js, test/category-cli.test.js
   - Interface: category: summary "Add or list categories", subcommands ["add", "list"], prints "Added category <name>" or one name per line; rule: summary "Add or list categorization rules", subcommands ["add", "list"], `ledger rule add <pattern> <category>` prints "Added rule <n>: <pattern> -> <category>", list prints "<n>. <pattern> -> <category>"
   - Verified by: ledger-categories / Requirement: Categories / Scenario: Add and list categories, Scenario: Reserved name, Scenario: Existing category; Requirement: Rules / Scenario: Add a rule, Scenario: Rule for an unknown category; test/category-cli.test.js
4. Add the command `categorize`
   - File: src/commands/categorize.js, test/categorize-cli.test.js
   - Interface: summary "Categorize entries by the rules"; `ledger categorize` prints "Categorized <n> entries"
   - Verified by: ledger-categories / Requirement: Categorize / Scenario: Match ignores case, Scenario: First rule wins, Scenario: Category kept, Scenario: Transfers untouched; test/categorize-cli.test.js
