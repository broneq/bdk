# Part 06: Entry list and export

## Goal

`ledger list` and `ledger export` select entries by month, account and category and print them, or write them as CSV or JSON, as spec `ledger-views` says (design D8).

## Uses

From part 01, exactly as named:

- The book holds `accounts: string[]`, `categories: string[]` and `entries`, an entry being `{ date, description, amount, account, category: string | null, transfer?, recurring? }`, amounts in integer cents, dates `YYYY-MM-DD`.
- `src/cli.js`: `UsageError`; `parseArgs(args, names)`; `openBook(io)`; `readMonth(text)`, `requireAccount(book, name)`, `requireCategory(book, name)`. A command module in `src/commands/<name>.js` exports `summary` and `run(args, io)`, with `io = { cwd, today, out, write, err }`: `io.out(line)` writes a line and a line break, `io.write(text)` writes text as it is.
- `src/dates.js`: `monthOf(date)`.
- `src/money.js`: `formatCents(cents)`.
- `test/helpers.js`: `ledger(dir, ...args)` (returns `{ status, stdout, stderr }`), `newDir()`, `writeBook(dir, fields)`.

## Acceptance scenarios

- `ledger-views` / Requirement: Entry filters / Scenario: Month and account
- `ledger-views` / Requirement: Entry filters / Scenario: Entries without a category
- `ledger-views` / Requirement: Entry filters / Scenario: Invalid month
- `ledger-views` / Requirement: Entry list / Scenario: List entries
- `ledger-views` / Requirement: Entry list / Scenario: Nothing selected
- `ledger-views` / Requirement: Export / Scenario: CSV export
- `ledger-views` / Requirement: Export / Scenario: JSON export
- `ledger-views` / Requirement: Export / Scenario: Unknown format

## Tasks

1. Read the filter options and select the entries
   - File: src/filter.js, src/filter.test.js
   - Interface: readFilter(book, options): { month?, account?, category? } (month with readMonth, account with requireAccount, category with requireCategory unless it is "none", which selects category null); selectEntries(book, filter): Entry[] matching every given filter, sorted by date with a stable sort so equal dates keep book order
   - Verified by: ledger-views / Requirement: Entry filters / Scenario: Month and account, Scenario: Entries without a category; src/filter.test.js
2. Add the command `list`
   - File: src/commands/list.js, test/list-cli.test.js
   - Interface: summary "List entries"; `ledger list [--month] [--account] [--category]` prints "<date> <formatCents(amount)> <account> <category or -> <description>" per entry, or "No entries"
   - Verified by: ledger-views / Requirement: Entry list / Scenario: List entries, Scenario: Nothing selected; Requirement: Entry filters / Scenario: Invalid month, Scenario: Month and account, Scenario: Entries without a category; test/list-cli.test.js
3. Write entries as CSV or JSON, and add the command `export`
   - File: src/export.js, src/export.test.js, src/commands/export.js, test/export-cli.test.js
   - Interface: toCsv(entries): string, ending with "\n" (header "date,description,amount,account,category", amounts with formatCents, empty field for category null, a field with a comma, a double quote or a line break quoted with inner quotes doubled, every line ending "\n"); toJson(entries): string (array of { date, description, amount, account, category } with amount in cents, two-space indentation, final newline); command: summary "Export entries as CSV or JSON", `ledger export [--format csv|json] [filters]` (default csv; UsageError "unknown format <text>") writes the text with io.write (both texts end with their own line break; io.out would add a second one)
   - Verified by: ledger-views / Requirement: Export / Scenario: CSV export, Scenario: JSON export, Scenario: Unknown format; src/export.test.js, test/export-cli.test.js
