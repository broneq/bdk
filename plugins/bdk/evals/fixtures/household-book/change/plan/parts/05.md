# Part 05: Budgets and recurring entries

## Goal

`ledger budget set|list` and `ledger recurring add|list|run` work as specs `ledger-budgets` and `ledger-recurring` say (design D7). `budgetStatus` is the contract part 07 reuses for its budget report.

## Uses

From part 01, exactly as named:

- The book holds `categories: string[]`, `budgets: { category, limit }[]` (limit in cents), `recurring: { id, day, amount, description, account, category, from }[]` and `entries`, an entry being `{ date, description, amount, account, category: string | null, transfer?, recurring? }`, amounts in integer cents, dates `YYYY-MM-DD`. Transfer entries always have the category `null`.
- `src/cli.js`: `UsageError`; `parseArgs(args, names)`; `subcommand(command, args, names)` (checks `args[0]`; then `parseArgs(args.slice(1), <that subcommand's options>)`); `openBook(io)`, `writeBook(io, book)`; `readAmount(text)`, `readDate(text)`, `readMonth(text)`, `requireAccount(book, name)`, `requireCategory(book, name)`. A command module in `src/commands/<name>.js` exports `summary` and `run(args, io)`, with `io = { cwd, today, out, write, err }` (`out(line)` writes a line and a line break).
- `src/dates.js`: `monthOf(date)`, `monthsFrom(first, last)` (months `YYYY-MM`, inclusive; `[]` when `first` is after `last`).
- `src/money.js`: `formatCents(cents)`.
- `test/helpers.js`: `ledger(dir, ...args, { env }?)` (returns `{ status, stdout, stderr }`, `LEDGER_TODAY=2026-10-08` unless `env` overrides it), `newDir()`, `writeBook(dir, fields)`, `readBook(dir)`.

## Tasks

1. Set budgets and compute the status of a month
   - File: src/budgets.js, src/budgets.test.js
   - Interface: setBudget(book, category, limit): void (requireCategory; UsageError "budget must be positive" when limit <= 0; replaces in place, keeping the first position); budgetStatus(book, month): { category, limit, spent, left }[] in budget order, in cents, spent = minus the sum of the amounts of entries with that category and monthOf(date) === month, left = limit - spent
   - Verified by: src/budgets.test.js
2. Add recurring entries and compute the due entries
   - File: src/recurring.js, src/recurring.test.js
   - Interface: addRecurring(book, { amount, description, day, account, category, from }): string, returning "r<N>", N = 1 + book.recurring.length (UsageError "day must be 1 to 28" unless day is an integer 1-28); dueEntries(book, today): Entry[] per spec ledger-recurring "Due entries": for each month of monthsFrom(monthOf(from), monthOf(today)) the date <month>-<day, two digits>, kept when from <= date <= today and no entry has this recurring id and date; result sorted by date, then by the position of the recurring entry in book.recurring (never a text sort of the ids: r10 comes after r2); each { date, description, amount, account, category, recurring: id }
   - Verified by: src/recurring.test.js
3. Add the command `budget`
   - File: src/commands/budget.js, test/budget-cli.test.js
   - Interface: summary "Set or list monthly budgets"; subcommands ["list", "set"]; `ledger budget set <category> <amount>` prints "Budget <category> <formatCents(limit)>"; `ledger budget list [--month]` (default monthOf(io.today)) prints "<category> limit <limit> spent <spent> left <left>" per budget, or "No budgets"
   - Verified by: ledger-budgets / Requirement: Budgets / Scenario: Set a budget, Scenario: Replace a budget, Scenario: Budget for an unknown category; Requirement: Budget status / Scenario: Status of a month, Scenario: Over budget, Scenario: Refund lowers spent, Scenario: Current month by default, Scenario: No budgets; test/budget-cli.test.js
4. Add the command `recurring`
   - File: src/commands/recurring.js, test/recurring-cli.test.js
   - Interface: summary "Add, list or run recurring entries"; subcommands ["add", "list", "run"]; `ledger recurring add <amount> <description...> --day <day> [--account] [--category] [--from]` (amount with readAmount; UsageError "recurring add needs --day" without --day; account defaults to "main" and is checked with requireAccount, a given category with requireCategory; --from read with readDate, defaulting to io.today) prints "Added recurring <id>: <amount> <description> on day <day>"; list prints "<id> day <day> <amount> <account> <description>"; run appends dueEntries(book, io.today) and prints "Added <n> recurring entries"
   - Verified by: ledger-recurring / Requirement: Recurring entries / Scenario: Add a recurring entry, Scenario: Day out of range; Requirement: Due entries / Scenario: Due months, Scenario: Not due yet, Scenario: Start date respected, Scenario: Run twice; test/recurring-cli.test.js
