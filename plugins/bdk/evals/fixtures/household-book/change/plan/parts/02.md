# Part 02: Accounts and transfers

## Goal

`ledger account add|list` and `ledger transfer` work as spec `ledger-accounts` says (design D4).

## Uses

From part 01, exactly as named:

- `src/book.js`: `isName(text)`; the book holds `accounts: string[]` (starting `["main"]`) and `entries`, an entry being `{ date, description, amount, account, category, transfer? }` with amounts in integer cents.
- `src/cli.js`: `UsageError`; `parseArgs(args, names)`; `subcommand(command, args, names)` (checks `args[0]`; then `parseArgs(args.slice(1), <that subcommand's options>)`); `openBook(io)`, `writeBook(io, book)`; `readAmount(text)`, `readDate(text)`, `requireAccount(book, name)`. A command module in `src/commands/<name>.js` exports `summary` and `run(args, io)`, with `io = { cwd, today, out, write, err }` (`out(line)` writes a line and a line break); the dispatcher finds it by file name.
- `src/money.js`: `formatCents(cents)`.
- `test/helpers.js`: `ledger(dir, ...args)` (returns `{ status, stdout, stderr }`, `LEDGER_TODAY=2026-10-08`), `newDir()`, `writeBook(dir, fields)`, `readBook(dir)`.

## Tasks

1. Add accounts to a book and compute their balances
   - File: src/accounts.js, src/accounts.test.js
   - Interface: addAccount(book, name): void (UsageError "invalid name <name>" when !isName(name), "account <name> exists" when present; appends to book.accounts); accountBalances(book): { name, balance }[] in book.accounts order, balance in cents
   - Verified by: src/accounts.test.js
2. Add a transfer as two linked entries
   - File: src/transfers.js, src/transfers.test.js
   - Interface: transfer(book, { amount, from, to, date }): string, returning the id "t<N>", N = 1 + the number of distinct transfer ids in book.entries; errors as UsageError in this order: "transfer amount must be positive" (amount <= 0), "transfer needs two different accounts", then requireAccount for from and to; appends { date, description: "Transfer to <to>", amount: -amount, account: from, category: null, transfer: id } and { date, description: "Transfer from <from>", amount, account: to, category: null, transfer: id }
   - Verified by: src/transfers.test.js
3. Add the command `account` with the subcommands add and list
   - File: src/commands/account.js, test/account-cli.test.js
   - Interface: summary "Add or list accounts"; `ledger account add <name>` prints "Added account <name>"; `ledger account list` prints "<name> <formatCents(balance)>" per account; subcommand("account", args, ["add", "list"]); add takes no option, list none
   - Verified by: ledger-accounts / Requirement: Accounts / Scenario: Add an account, Scenario: Invalid account name, Scenario: Existing account, Scenario: Balances per account, Scenario: Missing subcommand; test/account-cli.test.js
4. Add the command `transfer`
   - File: src/commands/transfer.js, test/transfer-cli.test.js
   - Interface: summary "Move money between accounts"; `ledger transfer <amount> <from> <to> [--date <date>]` (date defaults to io.today) prints "Transferred <formatCents(amount)> from <from> to <to>"
   - Verified by: ledger-accounts / Requirement: Transfers / Scenario: Transfer between accounts, Scenario: Transfer ids, Scenario: Same account, Scenario: Negative transfer; test/transfer-cli.test.js
