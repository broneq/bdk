# Part 07: Reports

## Goal

`ledger report monthly|categories|budget` prints the tables of spec `ledger-reports` (design D9). The budget report reuses `budgetStatus` from part 05, so it never disagrees with `ledger budget list`.

## Uses

From part 01, exactly as named:

- The book holds `budgets: { category, limit }[]` and `entries`, an entry being `{ date, description, amount, account, category: string | null, transfer?, recurring? }`, amounts in integer cents, dates `YYYY-MM-DD`. Every report leaves out entries with a `transfer` id.
- `src/cli.js`: `UsageError`; `parseArgs(args, names)`; `subcommand(command, args, names)` (checks `args[0]`; then `parseArgs(args.slice(1), <that subcommand's options>)`); `openBook(io)`; `readMonth(text)`. A command module in `src/commands/<name>.js` exports `summary` and `run(args, io)`, with `io = { cwd, today, out, write, err }` (`out(line)` writes a line and a line break).
- `src/dates.js`: `monthOf(date)`.
- `src/money.js`: `formatCents(cents)`.
- `test/helpers.js`: `ledger(dir, ...args)` (returns `{ status, stdout, stderr }`, `LEDGER_TODAY=2026-10-08`), `newDir()`, `writeBook(dir, fields)`.

From part 05: `src/budgets.js` `budgetStatus(book, month): { category, limit, spent, left }[]`, in budget order, all in cents.

## Acceptance scenarios

- `ledger-reports` / Requirement: Report tables / Scenario: Unknown report
- `ledger-reports` / Requirement: Monthly report / Scenario: Two months
- `ledger-reports` / Requirement: Monthly report / Scenario: Year without entries
- `ledger-reports` / Requirement: Category report / Scenario: Spending per category
- `ledger-reports` / Requirement: Budget report / Scenario: Budget against spending
- `ledger-reports` / Requirement: Budget report / Scenario: Report without budgets

## Tasks

1. Render tables and compute the monthly report
   - File: src/reports/table.js, src/reports/table.test.js, src/reports/monthly.js, src/reports/monthly.test.js
   - Interface: renderTable(header: string[], rows: string[][], align: ("left" | "right")[]): string[] (columns joined by two spaces, padded to the widest cell, trailing spaces removed); monthlyRows(entries, year): string[][] of [month, income, expenses, net] as formatCents text, one per month of the year with a non-transfer entry, in month order
   - Verified by: src/reports/table.test.js, src/reports/monthly.test.js
2. Compute the category report
   - File: src/reports/categories.js, src/reports/categories.test.js
   - Interface: categoryRows(entries, month): string[][] of [category, spent]: spent is the negated sum of a category's negative non-transfer amounts in the month, "(none)" for category null, rows sorted by spent descending then name, then ["total", sum]; [] when no row
   - Verified by: src/reports/categories.test.js
3. Compute the budget report
   - File: src/reports/budget.js, src/reports/budget.test.js
   - Interface: budgetRows(book, month): string[][] of [category, limit, spent, left, status] from budgetStatus(book, month), status "ok" when left >= 0 else "over", then ["total", sums..., status of the total left]; [] without budgets
   - Verified by: src/reports/budget.test.js
4. Add the command `report`
   - File: src/commands/report.js, test/report-cli.test.js
   - Interface: summary "Print a report"; subcommands ["budget", "categories", "monthly"]; monthly takes --year (four digits, default the year of io.today; UsageError "invalid year <text>"), the others --month (readMonth, default monthOf(io.today)); headers ["month", "income", "expenses", "net"], ["category", "spent"], ["category", "limit", "spent", "left", "status"], amount columns right-aligned; prints the rendered lines, or "No entries" (monthly, categories) or "No budgets" (budget) without rows
   - Verified by: ledger-reports / Requirement: Report tables / Scenario: Unknown report; Requirement: Monthly report / Scenario: Two months, Scenario: Year without entries; Requirement: Category report / Scenario: Spending per category; Requirement: Budget report / Scenario: Budget against spending, Scenario: Report without budgets; test/report-cli.test.js
