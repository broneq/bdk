# Part 01: Book format and command dispatch

## Goal

The book is version 2 and old files migrate; commands are modules under `src/commands/` run by one dispatcher with options, help and `LEDGER_TODAY`; `add` and `balance` work as spec `ledger` says. Every later part builds on the contracts written here (design D1, D2, D3, D10), so they are exactly as named.
