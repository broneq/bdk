# Part 01: Count flag and usage line

## Goal

`tally total --count` prints the number of amounts after the sum, the usage line names the option, and the scenarios of the two modified requirements have their tests.

## Acceptance scenarios

- `tally` / Requirement: Total / Scenario: Total of added amounts (behaviour present)
- `tally` / Requirement: Total / Scenario: Empty ledger
- `tally` / Requirement: Total / Scenario: Count flag (behaviour present)
- `tally` / Requirement: Usage / Scenario: Help
- `tally` / Requirement: Usage / Scenario: Unknown command (behaviour present)

## Tasks

1. Print `Entries: <n>` after the sum when the argument after `total` is `--count`
   - File: bin/tally.js, test/total.test.js
   - Interface: command `tally total --count`; prints `Total: <sum>` then `Entries: <load().length>`, exit 0
   - Verified by: tally / Requirement: Total / Scenario: Count flag; a test in test/total.test.js that adds 5 and 2.5 and expects `Total: 7.50\nEntries: 2\n`; it passes at its first run, the behaviour is present
2. Name the option in the usage line
   - File: bin/tally.js, test/total.test.js
   - Interface: USAGE = "usage: tally add <amount> | tally total [--count]"
   - Verified by: tally / Requirement: Usage / Scenario: Help; a test in test/total.test.js that runs `tally --help` and expects that line, exit 0
3. Add the tests of the scenarios the code already satisfies
   - File: test/total.test.js
   - Interface: none
   - Verified by: tally / Requirement: Total / Scenario: Total of added amounts, Scenario: Empty ledger; tally / Requirement: Usage / Scenario: Unknown command; the existing test for the sum, new tests that run `tally total` in an empty directory (expects `Total: 0.00`, exit 0) and `tally frobnicate` (expects the usage line, exit 2); they pass at their first run, the behaviour is present
