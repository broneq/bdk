# Part 02: Export command

## Goal

`ledger export <file>` prints the CSV text of a JSON file of entries, using `toCsv` from `src/csv.js`.

## Acceptance scenarios

- `ledger-export` / Requirement: Export command / Scenario: Export a file

## Tasks

1. Add the executable module `bin/ledger.js` (`#!/usr/bin/env node`) with the subcommand `export <file>`: read the file, parse the JSON array, print `toCsv(entries)` to stdout, exit 0
   - File: bin/ledger.js, test/cli.test.js
   - Interface: command `ledger export <file>`; imports toCsv from src/csv.js
   - Verified by: ledger-export / Requirement: Export command / Scenario: Export a file; test/cli.test.js runs `spawnSync(process.execPath, ["bin/ledger.js", "export", <path>])` against a file in a temporary directory
2. Register the command
   - File: package.json
   - Interface: package.json `"bin": { "ledger": "bin/ledger.js" }`
   - Verified by: `npm test` passes; `node bin/ledger.js export <file>` as in task 1
