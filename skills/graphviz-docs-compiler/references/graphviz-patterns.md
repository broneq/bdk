# Graphviz Patterns for Documentation

## Common Diagram Types

### Flow Diagrams

```dot
digraph flow {
    rankdir=TB;
    node [shape=box, style=filled, fillcolor=lightblue];

    "Start" [shape=ellipse, fillcolor=lightyellow];
    "Process 1" -> "Process 2";
    "Process 2" -> "Decision" [label="data"];
    "Decision" -> "End" [label="✓", style=bold];
    "Decision" -> "Error" [label="✗", style=dashed, color=red];
    "End" [shape=ellipse, fillcolor=lightgreen];
}
```

### Class/Component Diagrams

```dot
digraph classes {
    rankdir=TB;
    node [shape=record, style=filled, fillcolor=lightblue];

    Parser [label="{XMLParser|+ parse()\l+ validate()\l}"];
    Loader [label="{XMLLoader|+ load()\l+ extract()\l}"];
    Document [label="{XMLDocument|+ lines\l+ metadata\l}"];

    Parser -> Loader [label="uses"];
    Loader -> Document [label="creates"];
}
```

### Data Flow Diagrams

```dot
digraph dataflow {
    rankdir=LR;
    node [shape=cylinder, style=filled, fillcolor=lightyellow];

    Input [label="Input\nData"];
    Output [label="Output\nData"];

    node [shape=box, fillcolor=lightblue];
    Transform [label="Transform"];
    Validate [label="Validate"];

    Input -> Validate -> Transform -> Output;
}
```

## Style Guidelines

### Colors

- **Input/Output**: `lightyellow` (ellipse or cylinder)
- **Processing**: `lightblue` (box)
- **Success**: `lightgreen` (ellipse)
- **Error/Warning**: `lightcoral` or `red`

### Arrows

- **Normal flow**: Solid line
- **Error path**: Dashed line with `style=dashed`
- **Optional**: Dotted line with `style=dotted`
- **Important**: Bold with `style=bold`

### Labels

- Use Unicode symbols: ✓ ✗ ⚠ ➜ ⊕
- Keep labels short and descriptive
- Use `\l` for left-aligned text in records
- Use `\n` for line breaks in labels

## File Organization

```
docs/
├── module_name.md              # Main documentation
└── module_name/
    ├── diagrams/
    │   ├── architecture.dot    # Source files
    │   ├── dataflow.dot
    │   └── components.dot
    └── images/                 # Generated by compile_diagrams.py
        ├── architecture.svg
        ├── dataflow.svg
        └── components.svg
```

## Markdown Integration

In your documentation, reference diagrams like this:

```markdown
## Architecture

![Architecture](module_name/images/architecture.svg)

Source: [`diagrams/architecture.dot`](module_name/diagrams/architecture.dot)
```

The `compile_diagrams.py` script will automatically convert code blocks to this format.
