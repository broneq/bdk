# BDK - Broneq Dev Kit

A Claude Code plugin packaging reusable dev workflows, skills, agents and hooks into a single installable unit.

> **Status:** BDK v3 is being rebuilt on `staging/v3`. The latest release is `v2.7.0`; its documentation is the [README at that tag](https://github.com/broneq/bdk/blob/v2.7.0/README.md).

## Installation

1. Add the BDK marketplace source:
   ```
   /plugin marketplace add broneq/bdk
   ```
2. Install:
   ```
   /plugin install bdk@bdk
   ```
