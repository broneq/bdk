# Proposal

## Why

Issue #292: the `/bdk:plan` orchestrator eval cases `plan-verify-written` and `plan-budget-spent` scored 0.64 and 0.71 on `staging/v3`. In the failing runs the main thread's own `bdk plan check` call was denied ("don't-ask mode") although the run grants `Bash(*/bin/bdk *)`, and the orchestrator stopped before the verifier. Reproduced on 2026-10-09 (Claude Code 2.1.292): `plan-verify-written` scored 0.52 over 3 runs; the denied commands were `"<root>/bin/bdk" plan check ...` (quoted path) and the same followed by `; echo "exit=$?"`.

## What Changes

- The check block of `/bdk:plan` names the command unquoted and as the whole Bash command (no `cd`, `;`, `&&`, `echo`), the only form the grant `Bash(${CLAUDE_PLUGIN_ROOT}/bin/bdk *)` of the skill and the eval grant `Bash(*/bin/bdk *)` match.
- The spec `bdk-plan` states that the check call is a single grant-matching command.
- Both eval cases are measured at 1.00 over 3 runs.
